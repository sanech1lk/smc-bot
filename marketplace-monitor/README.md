# Marketplace Monitor

Локальное веб-приложение: следит за новыми объявлениями на **OLX.pl** и **Vinted.pl**
по вашим фильтрам и присылает их в Telegram. Для **Facebook Marketplace** собирает
готовую ссылку поиска и открывает её по кнопке.

Работает на вашем компьютере, открывается в браузере по адресу http://127.0.0.1:8000

---

## 1. Что реально работает, а что нет (честно)

| Площадка | Как сделано | Надёжность |
|---|---|---|
| **OLX.pl** | Скачиваем страницу поиска (`requests`) и разбираем её (`BeautifulSoup`). Если OLX отвечает 403 — запасной путь через браузер Playwright. | Хорошая. Ломается, когда OLX меняет вёрстку (раз в год-два) — тогда правится `parsers/olx.py`. |
| **Vinted.pl** | Библиотека `vinted-api-kit` обращается к внутреннему API сайта. Запасная — `vinted-api-wrapper`. | Средняя. Vinted активно борется с ботами; библиотеки периодически перестают работать до обновления. Поиска по городу у Vinted нет. |
| **Facebook Marketplace** | **Не автоматизировано.** Только кнопка «Открыть поиск». | Официального API нет. Автоматический парсинг ненадёжен и может привести к блокировке аккаунта — поэтому его здесь нет (подробнее в разделе 8). |

**Важно про проверку кода.** Логика приложения (база, дубли, чёрный список, интерфейс,
планировщик) протестирована. Но запросы к настоящим olx.pl, vinted.pl и Telegram
при разработке проверить не удалось — среда разработки не имела к ним доступа.
Поэтому при первом запуске возможны мелкие правки: адрес поиска OLX для вашего города,
названия элементов на странице OLX, ID категорий Vinted. Если фильтр покажет
красную ошибку в столбце «Последняя проверка» — её текст подскажет, что не так.

## 2. Структура проекта

```
marketplace-monitor/
├── main.py              # сервер FastAPI: адреса API + планировщик
├── monitor.py           # логика: проверить фильтры, найти новые, отправить
├── database.py          # база SQLite (фильтры и найденные объявления)
├── notifier.py          # отправка сообщений в Telegram
├── config.py            # чтение/запись настроек (config.json)
├── parsers/
│   ├── __init__.py      # общие функции парсеров
│   ├── olx.py           # парсер OLX
│   ├── vinted.py        # парсер Vinted
│   └── facebook.py      # сборка ссылки поиска Facebook
├── static/
│   └── index.html       # вся страница интерфейса (HTML + JS)
├── requirements.txt     # список библиотек
├── config.example.json  # пример настроек
├── start.bat            # запуск двойным щелчком
└── start_hidden.vbs     # запуск без окна (для автозапуска)
```

При работе появятся ещё два файла: `config.json` (ваши настройки и токен)
и `monitor.db` (база). **Никому их не отправляйте** — там токен вашего бота.

## 3. Установка на Windows (один раз)

### Шаг 1. Python
1. Скачайте Python 3.12 с https://www.python.org/downloads/windows/
2. В установщике **обязательно поставьте галочку «Add python.exe to PATH»**, затем «Install Now».
3. Проверка: нажмите `Win + R`, введите `cmd`, Enter. В чёрном окне наберите:
   ```
   python --version
   ```
   Должно показать `Python 3.12.x` (подойдёт любая версия от 3.10).

### Шаг 2. Скачайте проект
На странице репозитория в GitHub выберите ветку с проектом → зелёная кнопка **Code** →
**Download ZIP**. Распакуйте и положите папку `marketplace-monitor` в удобное место,
например `C:\marketplace-monitor`.

### Шаг 3. Виртуальное окружение и библиотеки
В том же чёрном окне (`cmd`) выполните по очереди:
```
cd C:\marketplace-monitor
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
После `activate` в начале строки появится `(venv)` — значит, всё правильно.

> Используйте именно `cmd` («Командная строка»), а не PowerShell: в PowerShell
> команда `activate` часто запрещена настройками безопасности.

## 4. Telegram-бот

### Создать бота
1. В Telegram найдите **@BotFather** → `/start` → `/newbot`.
2. Придумайте имя и логин (логин должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...` — скопируйте его.

### Узнать chat_id
1. Найдите своего нового бота в Telegram и нажмите **Start** (без этого бот не сможет вам писать).
2. Напишите боту любое сообщение, например `привет`.
3. Откройте в браузере (подставьте свой токен вместо `ТОКЕН`):
   ```
   https://api.telegram.org/botТОКЕН/getUpdates
   ```
4. Найдите в тексте `"chat":{"id":123456789` — это число и есть ваш **chat_id**.

Если страница показывает пустой `"result":[]` — ещё раз напишите боту и обновите страницу.

## 5. Запуск

Самый простой способ: **двойной щелчок по `start.bat`**.

Или вручную в `cmd`:
```
cd C:\marketplace-monitor
venv\Scripts\activate
uvicorn main:app --reload
```
Откройте в браузере: **http://127.0.0.1:8000**

Остановить: в чёрном окне нажмите `Ctrl + C` или просто закройте окно.

(`--reload` перезапускает сервер при изменении кода — удобно, если вы правите файлы.
В `start.bat` этот флаг убран: для постоянной работы он не нужен.)

### Первые шаги в интерфейсе
1. Блок **Настройки**: вставьте токен и chat_id → **Тест уведомления**. В Telegram должно прийти сообщение.
2. Блок **Новый фильтр**: выберите площадку, введите слова (по-польски, как искали бы на сайте), цену, город → **Добавить в отслеживание**.
3. Нажмите **Проверить сейчас**.

**Как ведёт себя первая проверка.** Всё, что уже есть на сайте, приложение просто
запоминает и в Telegram **не шлёт** (иначе пришло бы 40 сообщений разом). Уведомления
приходят только об объявлениях, появившихся после первой проверки. Дальше проверка
идёт сама по таймеру (по умолчанию каждые 10 минут, минимум 3).

**Чёрный список** проверяется по названию объявления, без учёта регистра.
Слова пишутся через запятую: `uszkodzony, na części, zamienię`.

**Город** пишите по-польски (`Warszawa`, `Kraków`). Для OLX он подставляется в адрес
поиска. Если фильтр выдаёт ошибку 404 — проверьте написание города.

## 6. Автозапуск при старте Windows

1. Убедитесь, что приложение запускается через `start.bat`.
2. Нажмите `Win + R`, введите `shell:startup`, Enter — откроется папка автозагрузки.
3. В папке проекта щёлкните правой кнопкой по `start_hidden.vbs` → **Копировать**.
4. В папке автозагрузки: правая кнопка → **Вставить ярлык** (именно ярлык, не сам файл).

Теперь при входе в Windows приложение стартует в фоне, без окна. Интерфейс по-прежнему
на http://127.0.0.1:8000.

- **Остановить:** `Ctrl + Shift + Esc` → вкладка «Подробности» → `python.exe` → «Снять задачу».
- **Убрать автозапуск:** удалите ярлык из папки `shell:startup`.
- Компьютер должен быть включён и не в спящем режиме — в спящем режиме проверки не идут.

## 7. Если OLX или Vinted начали блокировать

Признаки: красная ошибка у фильтра — «заблокировал запрос», код 403 или 429,
«страница без списка объявлений».

**Сначала самое простое:**
1. Увеличьте интервал до 15–30 минут.
2. Уменьшите число фильтров (каждый фильтр — отдельный запрос).
3. Подождите несколько часов — временные блокировки по IP обычно снимаются сами.
4. Перезагрузите роутер, если у вас динамический IP.

**OLX — переключение на Playwright (настоящий браузер):**
```
venv\Scripts\activate
pip install playwright
playwright install chromium
```
После этого приложение **само** попробует Playwright, когда обычный запрос получит 403.
Чтобы использовать браузер всегда — поставьте галочку «Всегда открывать OLX через
браузер Playwright» в настройках. Это медленнее (5–10 секунд на фильтр).
Если появляется ошибка `NotImplementedError` — запускайте через `start.bat` (без `--reload`).

**Vinted — переключение на другую библиотеку:**
```
venv\Scripts\activate
pip install --upgrade vinted-api-kit
```
Если обновление не помогло — замените библиотеку (обе называются внутри одинаково,
поэтому старую нужно удалить):
```
pip uninstall -y vinted-api-kit
pip install vinted-api-wrapper
```
Перезапустите приложение — код сам определит, какая библиотека установлена.

**Если изменилась вёрстка OLX** (ошибка «страница без списка объявлений», а в браузере
сайт открывается нормально): в `parsers/olx.py`, функция `parse_html`, нужно поправить
названия элементов (`data-cy="l-card"`, `data-testid="ad-price"` и т.д.).

## 8. Facebook Marketplace: почему только кнопка

Официального API у Marketplace нет. Есть два пути:

**(а) Playwright с ручным входом в аккаунт** — технически возможно, но:
- Facebook распознаёт автоматизацию и **блокирует аккаунты**, иногда навсегда;
- без входа в аккаунт Marketplace почти ничего не показывает;
- вёрстка меняется постоянно, парсер ломается каждые несколько недель;
- это прямое нарушение правил Facebook.

**(б) Не автоматизировать** — приложение собирает ссылку поиска с вашими словами,
ценой и сортировкой «сначала новые» и открывает её в вашем обычном браузере.
Риск нулевой, но уведомлений в Telegram для Facebook нет.

В проекте реализован вариант **(б)**. Полностью автоматический парсинг Facebook
Marketplace ненадёжен, и рекомендовать его нельзя. Если всё же решите пробовать
вариант (а) сами — используйте **только отдельный аккаунт, не основной**.

Подсказка: в самом Facebook Marketplace можно сохранить поиск и включить для него
уведомления — это официальный и безопасный способ получать новые объявления.

## 9. Юридические риски и как их снизить

Это не юридическая консультация, а честное описание ситуации.

- **Vinted и Facebook** прямо запрещают автоматический сбор данных в своих правилах (ToS).
  Последствия — блокировка IP или аккаунта.
- **OLX** также запрещает автоматизацию в регламенте и может ограничить ваш IP.
- Приложение не входит ни в какие аккаунты OLX и Vinted — блокировать там, кроме IP, нечего.

**Как уменьшить риски:**
- только личное использование: не перепродавайте и не публикуйте собранные данные;
- интервал не меньше 10 минут, немного фильтров (до 5–10);
- паузы между запросами уже встроены (3–8 секунд, случайные);
- запросы идут с заголовком обычного браузера (`User-Agent` в `parsers/olx.py`);
- не используйте основной аккаунт Facebook для любых экспериментов с автоматизацией;
- если пришла блокировка — остановитесь и подождите, а не обходите её напором.

## 10. Частые проблемы

| Проблема | Решение |
|---|---|
| `python` не является командой | Python установлен без галочки «Add to PATH» — переустановите с галочкой. |
| `uvicorn` не является командой | Не активировано окружение: выполните `venv\Scripts\activate`. |
| Страница не открывается | Проверьте, что окно с сервером не закрыто и адрес именно `http://127.0.0.1:8000`. |
| Порт занят (`address already in use`) | Приложение уже запущено (например, автозапуском). Либо запустите на другом порту: `uvicorn main:app --port 8001`. |
| Тест Telegram: «неверный chat_id» | Нажмите Start у своего бота и перепроверьте число. |
| Нет новых объявлений | Это нормально сразу после первой проверки. Новые придут, когда появятся на сайте. |
| Хочу начать с чистого листа | Остановите приложение и удалите файл `monitor.db`. |

### Как добавить свою категорию
- **OLX:** откройте категорию на olx.pl, скопируйте часть адреса после `olx.pl/`
  (например `elektronika/telefony`) и добавьте строку в словарь `CATEGORIES` в `parsers/olx.py`.
- **Vinted:** откройте категорию на vinted.pl; в адресе будет число
  (`/catalog/2994-electronics` → `2994`). Добавьте его в `CATEGORIES` в `parsers/vinted.py`.
  ID, которые уже стоят в файле, сверьте таким же способом — Vinted иногда их меняет.
