# PC Optimizer

Утилита для Windows 10/11, настраивающая систему на максимальный FPS.
Собрана под конкретную конфигурацию: **RTX 4060 + Core i5-14400F + 32 ГБ ОЗУ**.

Главное отличие от «ускорителей ПК» из интернета: здесь нет ни одной правки
«на удачу». Каждая оптимизация имеет объяснимый механизм, честную оценку
эффекта и **автоматический бэкап прежнего состояния** — любое изменение
откатывается одной командой.

---

## Быстрый старт

1. Скопируйте папку `pc-optimizer` на свой ПК с Windows.
2. Запустите **`START.bat`** — он сам запросит права администратора.
3. Начните с пункта **2 (Diagnostics)** — он ничего не меняет, только показывает,
   что именно теряет FPS на вашей машине.
4. Затем пункт **1 (GUI)** или **3 (профиль gaming)**.

Из PowerShell (от имени администратора):

```powershell
cd путь\к\pc-optimizer

.\Optimize-PC.ps1                                  # диагностика, ничего не меняет
.\Optimize-PC.ps1 -Action list                     # все оптимизации и их состояние
.\Optimize-PC.ps1 -Action apply -Preset gaming -WhatIf   # что будет сделано
.\Optimize-PC.ps1 -Action apply -Preset gaming     # применить
.\Optimize-PC.ps1 -Action restore                  # откатить всё обратно
.\Optimize-PC.ps1 -Action clean                    # очистка мусора и кэша шейдеров
```

Если PowerShell ругается на политику выполнения:

```powershell
powershell -ExecutionPolicy Bypass -File .\Optimize-PC.ps1
```

## Что внутри

| Файл | Назначение |
|------|-----------|
| `START.bat` | Меню запуска с повышением прав |
| `Optimize-PC.ps1` | Консольная версия: report / list / apply / restore / clean |
| `Optimize-GUI.ps1` | Окно с галочками и описанием каждой оптимизации |
| `lib/Common.ps1` | Логи, права, реестр, службы, бэкап и откат |
| `lib/Tweaks.ps1` | Каталог оптимизаций (данные, не код) |
| `lib/Report.ps1` | Диагностика железа и поиск узких мест |
| `lib/Clean.ps1` | Очистка временных файлов и кэша шейдеров |

Бэкапы и логи: `C:\ProgramData\PCOptimizer\`

## Профили

| Профиль | Что входит |
|---------|-----------|
| `safe` | HAGS, игровой режим, отключение Game DVR, оптимизации оконного режима |
| `gaming` | `safe` + схема электропитания, приоритеты MMCSS, сетевой троттлинг, приоритет активного окна, эффекты рабочего стола, телеметрия |
| `max` | `gaming` + отключение сжатия памяти (для 32 ГБ), алгоритм Нейгла |

Отдельные пункты применяются по идентификатору:

```powershell
.\Optimize-PC.ps1 -Action apply -Tweak hags,gamedvr-off,power-ultimate
```

## Оптимизации и реальный эффект

| Id | Что делает | Ожидаемый эффект |
|----|-----------|------------------|
| `hags` | Аппаратное планирование GPU | +0–3% FPS, ниже задержка; обязателен для Reflex и DLSS Frame Generation |
| `gamedvr-off` | Отключает фоновую запись Xbox Game Bar | +2–6% FPS |
| `game-mode` | Игровой режим Windows | Стабильнее 1% low |
| `windowed-opt` | Flip-model и VRR для игр в окне | Задержка как в полном экране, работает G-Sync в окне |
| `mmcss-games` | Приоритет игровых потоков и GPU-очереди | Меньше просадок при фоновой нагрузке |
| `net-throttle-off` | Снимает лимит ~10 000 пакетов/с | Заметно в сетевых играх |
| `prio-foreground` | Больше квантов CPU активному окну | Небольшой прирост 1% low |
| `power-ultimate` | Максимальная производительность + PCIe/USB без энергосбережения | Ровнее фреймтайм, нет паркинга ядер |
| `visual-fx` | Отключает анимации и прозрачность | Разгружает DWM; на FPS в полном экране влияет слабо |
| `svc-diagtrack` | Отключает службу телеметрии | Убирает фоновые всплески CPU и диска |
| `mem-compression-off` | Отключает сжатие памяти (только 32 ГБ+) | Снимает нагрузку на CPU |
| `net-nagle` | Отключает алгоритм Нейгла | −10–40 мс к пингу, на FPS не влияет |

Только вручную (в профили не входят):

| Id | Почему не в профиле |
|----|--------------------|
| `vbs-off` | Даёт больше всех (+5–15% FPS в CPU-зависимых играх), но **снижает защищённость системы**. Нужен флаг `-AllowSecurityTradeoffs`. Часть античитов требует VBS включённым |
| `fso-off` | Отключение оптимизаций полноэкранного режима: старым играм помогает, новым мешает. Только под конкретную игру и с замерами |
| `gpu-msi` | Прерывания MSI. На RTX 4060 со свежим драйвером уже включены — утилита это проверит |
| `svc-sysmain` | Спорно. Microsoft рекомендует оставлять включённой; на HDD отключать нельзя |
| `fast-startup-off` | На FPS не влияет, но лечит накопление проблем с драйверами |

## Чего утилита сознательно НЕ делает

Эти «твики» кочуют по форумам и видео, но на современной Windows 11 они либо
бесполезны, либо вредны — поэтому их здесь нет:

* **Отключение файла подкачки.** Даже с 32 ГБ часть игр падает без него.
* **«Очистка ОЗУ» / RAM cleaner.** Принудительно выгружает то, что понадобится
  через секунду. Итог — фризы вместо прироста.
* **Prefetch/Superfetch «в ноль», массовое отключение служб.** Ломает поиск,
  Windows Update и Store ради нулевого прироста FPS.
* **`bcdedit /set disabledynamictick no`, хаки таймера, «игровые» DNS,
  чистка реестра.** Ни один замер не показывает воспроизводимого эффекта.
* **Разгон GPU/CPU.** Это делается вручную, с тестами на стабильность
  (MSI Afterburner + OCCT), а не скриптом вслепую.

## Что скрипт сделать не может — а прирост там самый большой

Порядок важен: сверху то, что даёт больше всего FPS на вашей сборке.

1. **XMP в BIOS.** i5-14400F очень чувствителен к скорости памяти. Память,
   работающая на 4800 МГц вместо 6000 (или 2133 вместо 3200 для DDR4) — это
   потеря до 15% FPS. Включается одним пунктом в BIOS. Диагностика утилиты
   покажет, включён ли профиль.
   **Важно:** на чипсетах Intel H610/H510/H410 разгон памяти заблокирован —
   пункта XMP там нет, и базовая частота является потолком платформы.
   Утилита определяет чипсет и в этом случае не советует невозможное.
2. **Два модуля памяти вместо одного.** Одноканальный режим отнимает 10–25%
   FPS. Планки ставятся в слоты **A2** и **B2**.
3. **Частота монитора.** Проверьте, что в настройках выставлены не 60 Гц,
   а максимум панели. Утилита это тоже покажет.
4. **Resizable BAR** — в BIOS включить *Above 4G Decoding* и *Re-Size BAR
   Support*. Для RTX 4060 это +2–8% в ряде игр.
5. **Свежий драйвер NVIDIA** (nvidia.com или NVIDIA App). В новых играх
   Game Ready-драйвер даёт до +15%.
6. **Панель управления NVIDIA → Управление параметрами 3D:**
   * Режим управления электропитанием → *Предпочтителен режим максимальной производительности*
   * Режим низкой задержки → *Вкл.* (для соревновательных игр — *Сверхвысокий*)
   * Кэш шейдеров → *10 ГБ*
   * Вертикальный синхроимпульс → *Выкл.*; при G-Sync — *Вкл.* + ограничение FPS на 2–3 кадра ниже частоты монитора
7. **DLSS в самих играх.** Quality/Balanced на RTX 4060 — это +30–60% FPS,
   больше, чем все системные твики вместе взятые.
8. **8 ГБ видеопамяти.** В 1440p ультра-текстуры часто упираются в VRAM: это
   даёт фризы, а не низкий средний FPS. Снижение текстур на одну ступень
   лечит рывки лучше любой оптимизации Windows.
9. **Температуры.** RTX 4060 сбрасывает частоты после ~80 °C. Пыль в радиаторе
   и слабый продув корпуса стоят больше, чем весь этот скрипт.

## Безопасность и откат

* Перед изменениями создаётся **точка восстановления Windows**
  (отключается флагом `-NoRestorePoint`).
* Каждое изменённое значение реестра, каждая служба и схема электропитания
  записываются в JSON-бэкап: `C:\ProgramData\PCOptimizer\backups\backup-*.json`.
* Полный откат последнего набора:

  ```powershell
  .\Optimize-PC.ps1 -Action restore
  ```

* Откат конкретного бэкапа:

  ```powershell
  .\Optimize-PC.ps1 -Action restore -BackupFile "C:\ProgramData\PCOptimizer\backups\backup-2026-08-16_12-00-00.json"
  ```

* Предпросмотр без изменений — флаг `-WhatIf` у любой команды.

## Как честно замерить результат

Твик без замера — вера, а не оптимизация.

1. Возьмите **один и тот же отрезок игры** (та же локация, то же время суток,
   те же настройки графики).
2. Включите оверлей MSI Afterburner / RTSS или встроенный счётчик NVIDIA App.
3. Смотрите не только средний FPS, но и **1% low** — именно он отвечает за
   ощущение плавности.
4. Меняйте по одному пункту за раз. Если прироста нет — откатывайте.

Реалистичные ожидания для этой сборки: от чистой Windows «из коробки»
профиль `gaming` обычно даёт **3–8%** среднего FPS и заметно более ровный
фреймтайм. Плюс ещё 5–15% отдельно даёт `vbs-off`, если вы готовы на
компромисс с безопасностью. Всё, что обещает «+50% FPS одной кнопкой», —
неправда: такой прирост даёт только DLSS, XMP или апгрейд железа.

## Требования

* Windows 10 (1809+) или Windows 11
* Windows PowerShell 5.1 (входит в систему) или PowerShell 7+
* Права администратора — для применения и отката изменений
  (диагностика работает и без них)
